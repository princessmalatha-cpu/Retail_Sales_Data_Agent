
# Retail Sales Data Analysis - Databricks Genie

We are using data agent to analyze the data in Natural language and respond in SQL language.


## 📌 Project Overview
This project analyzes retail sales data to help a store manager understand sales trends, customer demographics, and time-based buying patterns to make data-driven business decisions.

The project is built in **Databricks** using **Genie** (AI/BI Data Agent) to allow natural language querying of the sales data.

## 🎯 Business Problem
The store manager wants to answer:
- What are the overall sales trends?
- Which gender purchases which products the most?
- What is the relationship between customer age and product categories?
- At what time of day / time of month do we have the most sales?
- When should we release specials or discounts?
